# pokefit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** A Python engine + local web UI that scales a Pokémon 3MF to fit the user's Pokéball, cuts two magnet pockets in its feet, checks mesh/printability, slices it with Bambu Studio (1× and 10×, supports off/auto) and exports a print-ready 3MF.

**Architecture:** `pokefit/` Python package (numpy/trimesh/manifold3d/shapely/scipy/pymeshlab) with pure functions per concern, a stdlib HTTP server exposing a JSON API and serving a bun-built TypeScript + three.js UI from `web/dist`. The CLI and server share one pipeline function.

**Tech Stack:** Python 3.11, trimesh 4.5, manifold3d 3.x, shapely 2, scipy, pymeshlab, embreex, pytest, mypy; bun 1.3, TypeScript, three.js.

**Spec:** `docs/superpowers/specs/2026-10-16-pokefit-design.md`

## Global Constraints

- Ball geometry derived from `pokeball.3mf` at runtime (cached JSON keyed by SHA-256); never hard-coded except as test expectations (inner R 36.806 ± 0.05, ring span ≈ 16 mm).
- Magnet pocket default Ø 4.18 × 2.20 mm; wall 0.8 mm; ceiling 0.6 mm; clearance 1.0 mm; washer default DIN 9021 M6 (OD 18, ID 6.4, t 1.6).
- Wall thickness warn < 0.8 mm, fail < 0.4 mm. Overhang threshold = profile `support_threshold_angle` (fallback 30°).
- Bambu CLI: `bambu-studio.exe --slice 0 --outputdir <dir> <in.3mf>`; read `<dir>/result.json` (`return_code`, `sliced_plates[].total_predication` s, `filaments[].total_used_g`, `warning_message`). Verified 2026-10-17 on 02.08.02.61.
- Slice profile: the user's own project `pokeball60goodPrinted.3mf` (Bambu X2D, PETG, 0.16 mm) by default, per-filament arrays reduced to the figure's filament count.
- Dark, mobile-friendly, touch UI; bun only (never npm/npx); TS only.
- No recursive deletes anywhere (including temp dirs); new temp dir names instead.
- Commits: conventional, signed "— Opus 5.5", no Claude mention, no co-author trailer.

## Review Focus

1. Figure 3MF whose object has a scaled/rotated build transform (dragon: 0.3 + yaw) → geometry and output must include that transform exactly once. Test: `test_model3mf.py::test_build_transform_baked`.
2. Feet too small for a pocket + wall → reported fail with measured inscribed radius, nothing cut. Test: `test_magnets.py::test_small_feet_fail`.
3. Pockets cannot reach the washer annulus at max scale → solver reduces offset/scale or reports the washer size needed. Test: `test_fit.py::test_annulus_forces_offset`.
4. Painted triangles survive the pocket cut (unchanged triangles keep exact paint string). Test: `test_model3mf.py::test_paint_roundtrip_after_cut`.
5. Bambu missing or slice failure → `warn` check with the error text, API still returns 200. Test: `test_slicer.py::test_missing_exe_warns`.

### Task 1: Shell geometry module (move flat_spot logic)
**Files:** Create `pokefit/__init__.py`, `pokefit/shell.py`; Modify `scripts/flat_spot.py` (thin wrapper); Test `tests/test_shell.py`.
**Produces:** `fit_sphere(p: ndarray) -> tuple[ndarray, float]`, `shell_spheres(m) -> tuple[(c,r_out),(c,r_in)]`, `cap_height(radius, chord) -> float`, `flat_spot(m, scale, disk, fill) -> trimesh.Trimesh`, `washer_seat_shell(shell_mesh, scale, washer: Washer) -> trimesh.Trimesh`.
- [x] tests: `fit_sphere` on a sampled sphere returns centre/radius to 1e-6; `cap_height(10, 12) == 2.0`; flat_spot of an icosphere hemisphere shell is watertight with a single body.
- [x] implement, run pytest, wrapper produces identical output to the committed `shell_flatbottom_60.stl` (volume within 0.1 %).

### Task 2: Ball cavity model
**Files:** `pokefit/ball.py`, `tests/test_ball.py`.
**Produces:** `@dataclass Ball(r_inner: float, ring_h: ndarray, ring_r: ndarray, ring_span: float, aperture: float)`, `load_ball(path_3mf, cache_dir) -> Ball`, `Cavity(ball, scale, washer, clearance)` with `.floor_z: float`, `.allowed_radius(z: ndarray) -> ndarray` (z relative to ball centre, final mm; negative where impossible), `.top_z`.
- Ring equator = centre of a sphere fitted to the ring's outward, sloped faces below `top − 3 mm`; `ring_r(h)` = min radial distance of the ring section at depth h (0.25 mm steps) over both rings; aperture = min of `ring_r`. Outside the ring span the allowed radius is also capped by the aperture (figure must pass the ring when the ball is closed).
- [x] tests: real `pokeball.3mf` → `r_inner` 36.806 ± 0.05, span 15.5–17.0, aperture 28.5–29.5; `Cavity(scale 0.6, M6)` floor = −Ri·s + cap_height(Ri·s, 18) + 1.6; allowed at equator ≤ ring_r(0)·0.6 − 1.

### Task 3: 3MF reader/writer with paint
**Files:** `pokefit/model3mf.py`, `pokefit/paint.py`, `tests/test_model3mf.py`, `tests/test_paint.py`.
**Produces:** `Part(name, extruder, vertices, faces, tri_attrs: list[dict[str,str]])`, `FigureObject(id, name, extruder, parts)`, `Project(path, objects, colours, settings)`, `read_project(path) -> Project` (STL/OBJ → one object one part), `world_parts(project, obj_id) -> list[Part]` (component ∘ build transform applied), `write_project(src: Project, obj: FigureObject, parts, out_path, copies=1, plate_xy=None)`; `paint.decode_majority(code: str) -> int` (Bambu TriangleSelector hex, reversed nibbles), `face_colours(part, colours, default_extruder) -> ndarray`.
- [x] tests: decode "4"→1, "8"→2, "0C"→3, "1C"→4, split code majority; synthetic 3MF round trip keeps paint per triangle; dragon world bbox height ≈ 0.3 × native; `test_build_transform_baked`; `test_paint_roundtrip_after_cut` (nearest-triangle transfer, untouched faces exact).

### Task 4: Fit solver
**Files:** `pokefit/fit.py`, `tests/test_fit.py`.
**Produces:** `FitResult(max_scale, scale, offset_xy, limiting_point, limiting_z, margin)`, `prepare_points(vertices) -> HullPoints` (per-z-bin 2D hull points, bins 1/200 of height, each with z-min/max), `max_scale(points, cavity, pockets_unit=None, annulus=None) -> FitResult`, `check_fit(points, cavity, scale, offset) -> float` (worst margin mm).
- Feasibility at scale s: convex min over offset of max_i(|s·q_i + o| − allowed(z_i)); Nelder-Mead from hull centroid + 4 restarts; annulus term added when pockets given. Bisection to 0.1 %.
- [x] tests: sphere radius 1 → max scale analytic (cavity sphere minus clearance at its height), off-centre figure gets offset ≈ −centre, `test_annulus_forces_offset`.

### Task 5: Magnet pockets
**Files:** `pokefit/magnets.py`, `tests/test_magnets.py`.
**Produces:** `Pocket(x, y, d, depth)`, `find_feet(mesh, z_probe=0.3) -> list[Polygon]`, `auto_pockets(mesh, spec) -> tuple[list[Pocket], list[Check]]`, `validate_pockets(mesh, pockets, wall, ceiling) -> list[Check]`, `cut_pockets(parts, pockets) -> parts` (manifold difference on parts the cylinder intersects).
- [x] tests: two-footed box → pockets at foot centres ±0.05; single 30×10 foot → 2 pockets on major axis; `test_small_feet_fail`; cut result watertight, volume reduced by π·r²·depth ± 2 %.
