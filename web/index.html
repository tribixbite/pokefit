      pokefit — fit any figure inside a Pokéball, with magnets

      pokefit takes a 3D-printable figure (3MF, STL or OBJ), scales it to the largest size that fits inside a printed Pokéball, cuts pockets for magnets into its underside so it snaps onto a steel washer glued in the ball, checks that it will print, and exports a ready-to-slice Bambu Studio 3MF with its painted colours.

      How to use it

      1. Open a figure — drop a .3mf, .stl or .obj on the page. Files with several figures get a picker.
      2. Pick the ball — the 60 % or 100 % ball, or type the inner diameter of yours. Set the clearance to the walls.
      3. Pick the washer — plain or zinc-plated steel (stainless is not magnetic). Compare washers shows which allows the largest figure.
      4. Magnets — 1, 2 or 3 pockets for 4 × 2 mm disc magnets are placed automatically; drag them in the underside view. The underside does not have to be flat: a pocket may go into a sloped or raised spot, but never below the plane the figure stands on.
      5. Turn it — rotate about X, Y and Z by any angle (45° works) if the model is not standing upright.
      6. Export — the figure 3MF (opens as a Bambu Studio project), an import variant whose colours are renumbered to your own project's filament slots (for Import geometry only), and a JSON report.

      What it checks

      • Fit against the ball's inner sphere, the connector rings and the ring opening the figure must pass through when closing.
      • Mesh soundness: closed surface, consistent normals, degenerate faces, separate shells.
      • Wall thickness, overhangs that need support, layers that start in mid-air, and bed contact (brim advice).
      • Magnet pockets: wall around each pocket, material above it, how high it sits above the washer, and whether it is over the steel.

      Privacy

      Everything runs in your browser: the same Python engine as the desktop version, compiled to WebAssembly (Pyodide). Your files are never uploaded. The first visit downloads about 30 MB, which the browser then caches.

      Local version (print time and filament)

      Print time, filament use and the supports verdict come from Bambu Studio itself, which only runs on your computer. The local version slices with your own printer profile:

      git clone https://github.com/tribixbite/pokefit
cd pokefit && pip install -e .
cd web && bun install && bun run build && cd ..
python -m pokefit serve --open

      Questions

      Are my files uploaded anywhere?
      No. The analysis runs in your browser (Python compiled to WebAssembly); files never leave your device.
      Which washer and magnets should I use?
      A plain or zinc-plated steel washer (stainless is not magnetic), glued inside the ball's bottom, and 4 × 2 mm disc magnets pressed into the pockets. A 1/4 inch × 1 inch fender washer or a DIN 9021 M6 washer works for the 60 % ball; Compare washers shows which gives the largest figure.
      Which file types work?
      3MF (including Bambu Studio projects with painted colours and several figures), STL and OBJ.
      How do I get print time and filament estimates?
      Those come from Bambu Studio itself, which runs only on your computer: install the local version of pokefit (Python) to slice with your own printer settings.
